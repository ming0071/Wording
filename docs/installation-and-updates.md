# 安裝與更新

從 [GitHub Releases](https://github.com/ming0071/Wording/releases) 下載 Windows x64 的 `Wording-版本-win-x64-Setup.exe`，執行後依畫面安裝。桌面捷徑可自行勾選，開始功能表會有 Wording。

程式包包含 .NET 執行環境與完整教材。內嵌字典需要 Microsoft Edge WebView2 Runtime，AI 功能需要已登入的 Codex CLI。沒有 AI 時仍可使用單字庫與複習。

## 檔案位置

程式預設位於 `%LOCALAPPDATA%\Programs\Wording`。個人詞庫與學習紀錄位於 `%LOCALAPPDATA%\Wording\wording.db`，設定位於同一資料夾的 `settings.json`。可從「設定與備份」查看或開啟資料目錄。

安裝器只替換程式檔，不會把作者的個人資料帶到你的電腦。一般安裝、更新及解除安裝不要求管理員權限，解除安裝會保留學習資料。

## 使用隨附教材

到「設定與備份」的「隨附教材」，選擇需要的教材後按「匯入所選教材」。完整詞庫已包含片語補充，起始教材與完整詞庫有部分重疊，通常選擇一份即可。

教材檔案也位於程式資料夾的 `content`，含格式範例及來源說明。教材只有按下匯入才加入詞庫，程式更新不會自動覆寫個人修改。

## 取得新版

開啟程式時與使用期間每六小時會檢查正式 Release，有新版時顯示通知。也可在設定頁按「檢查更新」。關閉程式時不會有背景常駐服務，下次開啟再檢查。程式只讀取公開版本資訊，不需要 GitHub 登入，不上傳詞庫或學習紀錄。

按「下載並更新」後，程式會下載新版 EXE 並核對 GitHub 的檔案摘要，使用者不需要手動下載校驗檔。未保存的詞義編輯需先保存；未提交的練習會先詢問是否結束，取消會保留當次練習。稍後可再按「安裝並重新開啟」。程式在安裝前建立資料備份，交由安裝器更新並重新開啟。

沒有網路、取消下載或校驗失敗時仍可使用目前版本。若安裝器顯示失敗，保留原有資料，可稍後重新下載安裝。安裝只處理程式目錄，備份與個人資料位於另一個目錄。

## 從舊版轉換

舊 ZIP 版沒有自動更新功能。先關閉舊版，下載並執行安裝 EXE，之後使用開始功能表或新桌面捷徑。相同 Windows 帳號與預設資料目錄會直接沿用既有資料。若先前以 `--data-dir` 指定資料目錄，需繼續使用相同啟動參數；程式內更新會保留這個參數。

第一次轉換後，舊 ZIP 資料夾仍存在，但不再作為日常啟動入口。換電腦或 Windows 帳號時，使用既有 ZIP 備份與還原功能搬移學習資料。
