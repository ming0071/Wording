## 實作審查與驗證

此節記錄實際程式的交叉審查。已修正程式、通過自動測試、完成人工介面操作是不同的證據，不互相替代。

### 已取得的驗證證據

- GitHub Windows CI 在 commit `40a21e9` 完成建置、41 個測試與 self-contained 發布：[執行紀錄 36228994567](https://github.com/ming0071/WordTrail/actions/runs/36228994567)。這項結果只代表該 commit；後續修正仍需新的 CI 結果。
- FSRS 以共同明示的參數、固定權重與關閉 fuzz 對照官方 Python 參考實作。58 個案例已用實際 C# 執行環境驗證；審查也找出套件與參考實作對經過天數的處理差異，並加入整天計算適配。細節見 [FSRS_VERIFICATION.md](FSRS_VERIFICATION.md)。
- 教材結構檢查通過 300 筆。根 agent 另逐筆檢查 300 筆詞義、英中例句與搭配詞，修正語意或詞義一致性問題。這是 AI 交叉審查，不是辭典授權、教師認證或教材絕對正確的保證。
- Codex 程序執行器的 7 個案例已透過實際程序通過，包括輸出讀取與程序生命週期；這不等同完整內容產生器或 GUI 整合已通過。
- 成品 ZIP 已下載，發布的應用程式已啟動。Computer Use 的應用程式授權請求逾時，尚未完成實際 UI 互動驗收。

### 實作審查發現與處置

| 審查發現或風險 | 實際處置 | 目前證據與狀態 |
| --- | --- | --- |
| 不同 FSRS 套件預設值與天數算法不同，可能得到不同排程 | 固定版本、共同參數與整天計算適配；保留參考結果 fixture | 58 個實際數值案例通過；包含在既有 CI 測試中 |
| 重試、重複送出、舊版本評分或中途故障可能改壞排程 | 同一交易寫入排程與紀錄；唯一 OperationId、版本檢查、故障注入與 Undo 邊界測試 | 資料層相關測試已在 `40a21e9` CI 通過 |
| UI 對不確定結果重新建立時間或評分，會破壞同一次操作的重試語意 | 固定完整 pending ReviewSubmission；重試沿用原評分、時間、操作 ID 與版本 | 已修改並新增桌面流程測試；待新 CI |
| 「已封存」篩選永遠空白，使用者無法從 UI 還原 | 查詢新增明確的 includeArchived 選項；「全部／已封存」使用它；加入「還原封存」按鈕 | 已修改；新增資料層與桌面流程測試，待新 CI 與 UI 操作驗證 |
| 還原封存可能重設學習狀態 | 保留原詞義、卡片、排程與歷史，只解除封存；測試涵蓋暫停與學習選擇 | 測試已新增，待新 CI。現行 SaveVocabularyAsync 也會標記為使用者編輯，之後種子更新不覆蓋該詞義 |
| 正在使用的 SQLite 資料直接複製、損壞備份或還原中斷可能遺失內容 | 一致快照、manifest 雜湊、結構與版本檢查、替換前驗證及失敗回退 | 備份／還原相關測試已在既有 CI 通過；後續補強仍需新 CI；GUI 流程未驗收 |
| 只排除已知 Codex 工具事件會放行新增或未知事件類型 | 回應 item 類型改為明確允許清單；拒絕未知類型 | 已修改並補測，待新 CI。回應檢查不能倒推阻止已發生的工具操作 |
| AI 回傳格式合法，但搭配詞或例句重複 | 驗證內容數量、非空字串、詞義 ID，並拒絕重複搭配詞／英文例句 | 已修改並補測，待新 CI；語意正確性仍需使用者確認 |
| 程序取消後清理無限等待，或 stdout／stderr 相互堵塞 | 平行讀取有上限的輸出，取消時終止程序樹，清理等待有期限 | 實際程序 7 個案例通過；待新 CI 整體確認 |
| 將完整 stderr 直接顯示可能暴露不必要的環境資訊；全部隱藏又無法排錯 | 僅對設定、額度、登入、網路等已知錯誤提供安全分類，其餘顯示一般錯誤 | 已修改並補測，待新 CI |
| 必須先填完整解釋才能用 AI，或產生結果直接污染已存內容 | 可只填詞條提出 AI 草稿；預覽、套用、保存三步分開；詞性等必要欄位保存前仍需確認 | 已修改並新增桌面流程測試，待新 CI 與實際 GUI 驗收 |
| 人工修改 AI 例句後仍保留 AI 來源，或不同欄位混用整張卡來源 | 詞義、搭配詞與每個例句保留各自來源；人工更改改為使用者來源 | 已修改並新增測試，待新 CI |
| 未保存編輯在切頁／關閉时遺失；保存期間新修改被錯誤標成已保存 | 加入 dirty 狀態與離開提示；第二輪審查另發現延遲保存的競態 | 一般 dirty 處理已實作；延遲保存競態正在修正，尚未驗證，不視為結案 |
| 把 ChatGPT 訂閱誤當通用 OpenAI API 額度 | 使用本機 Codex CLI 的 ChatGPT 登入路徑；不加入付費 API fallback | CLI 登入與最小生成已驗證；正式 C# 內容產生器端到端驗證進行中 |
| Codex 是代理程序，唯讀 sandbox 不代表無法讀取本機檔案 | 使用最小工作目錄、限制功能與結構化輸出；文件明示邊界 | 限制已實作，不能宣稱絕對隔離；不得以最小 CLI 測試取代完整整合驗證 |
| 本機沒有 Visual Studio／.NET SDK，無法在本機完成一般建置 | 依使用者要求保留原始碼，由 GitHub Windows CI 建置、測試與打包 | 私有 GitHub repo 已推送且既有 CI 成功；本機未安裝 SDK 或 Visual Studio |
