### 實作審查發現與處置

| 審查發現或風險 | 實際處置 | 目前證據與狀態 |
| --- | --- | --- |
| 不同 FSRS 套件預設值與天數算法不同，可能得到不同排程 | 固定版本、共同參數與整天計算適配；保留參考結果 fixture | 58 個實際數值案例通過；包含在既有 CI 測試中 |
| 重試、重複送出、舊版本評分或中途故障可能改壞排程 | 同一交易寫入排程與紀錄；唯一 OperationId、版本檢查、故障注入與 Undo 邊界測試 | 最新 CI 通過 |
| UI 對不確定結果重新建立時間或評分，會破壞同一次操作的重試語意 | 固定完整 pending ReviewSubmission；重試沿用原評分、時間、操作 ID 與版本 | 桌面流程測試在最新 CI 通過 |
| 「已封存」篩選永遠空白，使用者無法從 UI 還原 | 查詢新增明確的 includeArchived 選項；「全部／已封存」使用它；加入「還原封存」按鈕 | 資料層與桌面流程測試通過；GUI 操作未完成 |
