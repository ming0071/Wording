# Scenario Practice

從左側「情境練習」選擇閱讀或聽力，用自己的單字生成一篇文章與 3–5 題英文選擇題。題型參考 TOEIC 的理解、細節與推論練習；內容為 AI 原創，並非官方試題。

## Getting Started

1. 先新增或匯入單字，並在「設定與備份」完成 Codex 連線檢查。
2. 到「情境練習」選模式、主題、類型、長度與難度，按「生成新的練習」。
3. 閱讀文章或播放聽力，選完所有答案後提交。
4. 查看分數、正確答案、中文解析與原文依據；全文中文翻譯需自行展開。
5. 回想看解析前是否已理解目標詞義，再決定要不要評分或標星。

生成模型與速度在「設定與備份」選擇，清單由 Codex CLI 動態查詢；詞義補充、閱讀與聽力共用此設定。速度模式與額度說明見 [Codex 生成速度](configuration.md#codex-speed)。

頁面由上到下顯示練習設定、當次文章與題目、最近三個月的主題練習足跡。選項與主題色塊完整排列，整個頁面可用滑鼠滾輪或捲軸上下瀏覽。成功生成後隱藏設定；按「重新設定練習」可再次調整，按「返回當次練習」會隱藏設定並繼續作答，不會清除文章與答案。足跡一直直接顯示，不需展開。

生成後，作答區左側顯示文章或聽力播放器，右側顯示題目與作答後的檢討。文章與題目分開捲動，可以拖曳中間分隔線調整寬度；作答時提交按鈕固定在右側下方。文章或題目捲到底／頂時，繼續滾動會移動整個頁面。全文中文翻譯放在左側文章底部。

生成與原本的單字 AI 補充共用每日生成額度。生成失敗或取消會保留原本的練習；已開始的生成仍使用一次額度，不會自動重試。

## Options

第一次使用的預設如下；成功生成後，會記住這次使用的選項。

| 選項 | 可選內容 | 預設 |
| --- | --- | --- |
| 模式 | 閱讀、聽力 | 閱讀 |
| 主題 | 詞庫中可用的主題，可多選；幫我選 | 幫我選 |
| 閱讀類型 | 信件、公告、廣告、職場情境、有趣的文章、幫我選 | 幫我選 |
| 聽力類型 | 對話、獨白、幫我選 | 幫我選 |
| 長度 | 短篇 120–180、中篇 220–300、長篇 350–500 個英文單字 | 短篇 |
| 難度 | 輕鬆、適中、挑戰 | 適中 |
| 目標單字量 | 少量、適中、較多 | 適中 |
| 題數 | 3、4、5 | 4 |
| 聽力速度 | 慢速、正常、快速 | 正常 |

「有趣的文章」允許輕鬆故事、幽默、科幻與奇幻，仍以選定主題和指定詞義取材。閱讀包含理解、單字與文法題；文法填空放在題目中，文章保持完整。聽力使用理解、細節、目的與推論題。

短／中／長篇在少量模式下分別取 4／6／8 個目標詞義；適中增加 2 個，較多增加 4 個。詞彙不足時使用實際可用數量，其他英文詞彙由生成器依難度安排。

## Listening

聽力使用 Windows 已安裝且可用的英文合成語音，優先選美式英文。對話先採同一個聲音朗讀，尚未區分角色音色。

題目可先看，音訊可重播、暫停、繼續與停止；速度調整在下次從頭播放時生效。逐字稿與中文解析在提交後才顯示。離開情境練習頁會停止朗讀，返回時可從頭播放。

若顯示沒有可用的英文語音，請檢查 Windows 語音安裝與帳戶權限。閱讀練習不依賴語音。

## Word Selection

選字由程式先決定，再把詞義 ID、詞條、詞性與指定中文詞義傳給生成器。暫停、封存或略過的詞義不參與。

- 同時有未學與已學詞彙時，先為未學詞彙保留約一半位置，再抽取已學詞彙；不足時由剩餘詞彙補足。
- 已學詞彙依記憶穩定度與估計回想機率加權，較不穩定的詞義更容易出現。這只影響選材，不改寫 FSRS。
- 星號讓抽中權重乘以 1.6，不保證每篇出現。
- 最近七天已完成練習中的目標詞會降低權重；同次開啟程式最近三篇生成內容也會降權。詞庫較小時仍可能重複。
- 「幫我選」會提高近十四天較少練習主題的相對機率。

權重是第一版的可調整規則，位於 [PracticeSelector.cs](../src/Wording.Infrastructure/PracticeSelector.cs)。抽樣不重複選取同一詞義；所有主題共用既有學習進度。

## Feedback & FSRS

測驗分數不會自動換算為單字評分。目標詞義區會提示：**請回想看解析前，你是否已理解這個詞義。**

主要按鈕為「1 · 沒想起來」與「3 · 原本就懂」；展開後可選「2 · 勉強想起」或「4 · 輕鬆理解」。使用與複習頁相同的 FSRS 評分與排程。同名詞條的其他解釋共用這張卡，評分會更新整個詞條；生成器取材時仍使用當次指定的意思。

已到期的詞義與未學新詞可以評分。情境練習的新詞評分不受設定上限限制，上限設為 0 時也可評分；未到期詞義仍顯示下次複習時間，暫停或封存的詞條仍不可評分。

新詞在實際評分成功後才計入當天新詞學習數量，與複習頁共用紀錄。同一詞條只計一次；畫面顯示實際已開始數量／設定上限，允許例如 55 / 50，不自動提高設定上限。一般複習頁仍依每日名額提供尚未開始的新詞，已開始的到期卡不受新詞上限限制。

每篇練習的同一詞義只接受一次評分，重試不會重複更新。實際按下時會重新檢查資格，避免切去複習頁後使用舊狀態。可撤銷目前工作階段最後一次單字評分；若已在別處更新，會拒絕撤銷。撤銷仍保留已使用的新詞名額。

## Data

未提交的文章與答案會保留在記憶體中。切去單字庫記錄詞彙再回來，可以接著作答；關閉程式即清除。以新內容取代未提交練習，或切換閱讀／聽力模式時，會先顯示與單字庫相同風格的提示視窗。預設按鈕為「繼續作答」，Enter 或 Escape 都會保留當次內容；需明確按「取代並繼續」才會進行切換或重新生成。

提交後只保存完成時間、模式、主題與目標詞義 ID。熱力圖、次數和各主題最近日期只顯示最近三個月，舊紀錄在啟動或讀取練習歷史時清除。文章、作答與分數不存入資料庫。

練習足跡以主題色塊呈現：每個主題顯示總次數、閱讀／聽力各自次數與最近練習日期。顏色越深表示相對練習較多，尚未練習的主題以灰色顯示 0 次。同一篇練習若選了多個主題，每個主題各計一次，因此主題次數相加可能高於總練習次數。所有色塊直接顯示在頁面下方，可透過整頁捲動瀏覽。

手動單字評分仍屬正式複習紀錄，不隨三個月練習紀錄清除。完整 ZIP 備份包含練習完成紀錄與 FSRS 資料；個人選項另存在 `settings.json`。還原資料庫會清除當次練習，避免套用還原前的單字狀態。

## Prompts & Validation

提示詞獨立放在 [Prompts](../src/Wording.Infrastructure/Prompts)，建置與發行時複製到程式旁的 `Prompts` 資料夾：

| 檔案 | 用途 |
| --- | --- |
| `practice-common.txt` | 指定詞義、難度、字數、選項、原文依據與中文解析 |
| `practice-reading.txt` | 閱讀類型、有趣故事與文法題 |
| `practice-listening.txt` | 對話／獨白與適合聽力的題型 |

每次生成都重新讀取檔案，可以調整語氣與出題偏好。修改輸出結構時，也需要同步調整 [CodexPracticeGenerator.cs](../src/Wording.Infrastructure/CodexPracticeGenerator.cs) 的 schema 與驗證；只改提示詞不會放寬程式驗證。

回傳內容需通過英文欄位、字數、題數、四個不同選項、答案範圍、中文解析、指定詞義 ID 和原文摘錄檢查，才會替換畫面內容。這些檢查能排除結構錯誤，但無法保證每一題的語意判斷都正確。

生成格式會依閱讀／聽力模式限制題型，並指定當次題數、目標詞義數量與允許的 ID。閱讀的細節、目的與推論題都屬於理解題，不會因為這些分類名稱而被拒絕；其他驗證失敗會指出題號或不符合的數量，方便排查。

## Tests

```powershell
.\scripts\test.ps1 -Filter 'FullyQualifiedName~Practice'
```

涵蓋選字權重、生成驗證、重複提交、共享新詞計數、超過設定上限與 0 上限、大量到期卡、一般複習仍受限、到期檢查、撤銷、三個月保存、資料庫升級、備份還原，以及最小視窗的閱讀／聽力畫面。自動測試使用獨立資料庫與生成替身，不使用正式詞庫或 AI 額度。
