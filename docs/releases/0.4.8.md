# Wording 0.4.8

情境練習將「動詞片語」視為單字庫分類，不再當作情境主題。

- 閱讀與聽力的主題選項、「幫我選」隨機主題、主題練習足跡均移除「動詞片語」。
- 已保存的選擇會略過這個分類；若沒有其他主題，回到「幫我選」。
- 片語仍可依所屬的其他情境分類被選入文章；詞庫只有「動詞片語」分類時仍可生成自由情境練習。
- 單字庫與一般複習的分類保留；既有練習紀錄不刪除，完成總次數保留。

驗證閱讀／聽力的選項、舊偏好與歷史、隨機選題、片語仍參與選字，以及只有片語分類的詞庫。完整測試共 263 項通過。

## 相較 0.4.0 的累積更新

- 修正刪除重複詞義後的單字庫排列與搜尋結果。
- 複習的多組詞義共用一致的中文詞性、欄位順序與文字樣式，依視窗寬度排列為一、二或三欄；能完整容納時置中，長內容可捲動。
- 複習時使用已安裝的繁體中文（台灣）輸入法英文模式；未安裝時不切換輸入法。
- 情境練習的新詞評分可超過每日上限，仍計入今日數量，例如 55 / 50。
- 取消因到期卡數自動減量或暫停新詞；一般複習仍以到期詞優先，再依使用者設定的每日上限提供新詞。
- 補充 AI 協助開發與教材來源說明。

## 下載與更新

下載 Windows x64 ZIP，完整解壓後執行 `Wording.exe`。附件另提供 SHA-256 校驗碼與選用單字庫。程式包已包含 .NET，內嵌字典需要 Microsoft Edge WebView2 Runtime。

更新前先關閉 Wording，將完整新版內容替換至原本的程式資料夾，即可沿用捷徑。個人詞庫與練習紀錄保存在 Windows 使用者資料目錄，不包含在發行包內。
