# Wording 0.4.3

統一複習卡的中文詞性與欄位排列，修正各組資料缺少不同欄位時的閱讀差異。此版本目前僅更新原始碼與本機程式包，尚未發布 GitHub Release。

## 複習顯示

- 英文詞性縮寫與名稱統一顯示中文，例如 `n`／`noun` 顯示「名詞」、`adj` 顯示「形容詞」。翻卡前的提示與翻卡後的所有詞義都使用相同規則，並支援多種詞性組合。
- 各欄依同一順序呈現詞性、中文詞義、英文解釋、提示、搭配、同義詞、例句與筆記。不同字數或缺少欄位時，中文詞義、英文解釋與例句的起始位置仍對齊。
- 英文解釋使用相同字級與標示，未填寫時顯示「尚未提供英文解釋」。提示另外標示，避免兩種內容混淆。
- 原有詞性、英文解釋與提示資料不會被改寫；自訂詞性保持原樣。

## 驗證與更新

使用教材中的三組 `assignment` 詞義重現原本欄位差異，驗證中文詞性、缺少英文解釋的顯示、各欄對齊及不同視窗寬度。另檢查詞性轉換、單組／多組卡片切換與既有教材版面。

本機打包會更新固定的 `artifacts/Wording-current/Wording.exe`，個人詞庫與練習紀錄仍保存在原本的使用者資料目錄。
