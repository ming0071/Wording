# Wording 0.4.4

改善小視窗的複習閱讀與繁體中文（台灣）輸入法行為。此版本僅更新原始碼與本機程式包，尚未發布 GitHub Release。

## 複習版面

- 移除整張卡的縮放，維持單組與多組詞義的原本字級。
- 依可用寬度顯示一、二或三欄。三組詞義在中等寬度排列為兩組加下一列一組，窄視窗改為直向排列。
- 詞義過長時僅捲動內容，詞條、朗讀與評分按鈕固定顯示；換卡或翻卡回到內容頂端。
- 詞性、英文解釋與例句維持一致格式，並排時對齊欄位，單欄時依內容自然排列。

## 輸入法

進入複習頁先檢查已安裝的輸入語言。有繁體中文（台灣）時，使用該輸入法的英文模式，不切到英文（美國）；沒有時不切換輸入語言或中英模式。離開複習焦點後恢復原輸入語言。

## 驗證與更新

以一至三組詞義、實際教材的 `assignment` 與起始教材驗證窄、中、寬視窗的欄數、原本字級、捲動範圍、固定操作與換卡重設。輸入法測試涵蓋台灣與美國同時安裝、只有台灣、沒有台灣及不影響其他控制項。實際輸入法中英指示仍須在桌面驗收。

本機打包更新固定入口 `artifacts/Wording-current/Wording.exe`，個人詞庫與練習紀錄沿用原本的使用者資料目錄。
