# Wording 0.4.0

同一個單字的多組意思合成一張卡，擴充多益動詞片語，並更新閱讀與聽力功能的使用說明。

## 詞庫與複習

- 相同單字／片語合併為一個詞條，多組解釋、雙語例句與用法一起呈現，共用一個星號與複習卡。新增另一組解釋也會加入同一張卡。
- 舊詞庫在啟動時自動合併，JSON 匯入時也會整合重複詞條。合併前先備份；合併的卡片重設為未學，其他單字的複習進度保持原狀。
- 完整教材整理為 1,113 個單字／片語、1,385 組解釋，包含原本八個情境主題及新增的「動詞片語」主題；另提供 99 個動詞片語、102 組解釋的補充檔。
- 卡片移除教材聲明與來源網址，只保留學習內容。已匯入的文字會在啟動時先備份再清理，清理筆記不影響星號或排程；教材來源留在文件中。
- 未標星圖示使用灰色，單字庫的星號縮小，方便辨識已標記的詞條。

## 設定與功能展示

- 延續 0.3.7 的動態 Codex 模型與生成速度選單，跟隨目前 CLI 提供的清單；閱讀、聽力及詞義生成共用設定。
- 每日新詞預設 25 個，到期複習另計；開始複習時切換英文輸入，離開後恢復原輸入語言。已有個人設定會保留。
- README 補齊 Codex 閱讀／聽力測驗、中文解析與單字回饋說明，以清晰 PNG 和可展開的圖片取代舊 GIF，維持精簡版面。

## 驗證與更新

203 項 .NET 測試通過，涵蓋詞條合併、備份還原、交易回滾、多義卡片、舊 JSON 重複匯入與筆記清理。發行流程另檢查教材、發布腳本、Windows x64 自包含程式包與 SHA-256。

下載 `Wording-0.4.0-win-x64.zip`，完整解壓後執行 `Wording.exe`。單字與複習資料仍保存在 `%LOCALAPPDATA%\Wording`。這次詞庫結構升級後，請使用 0.4.0 或更新版本開啟資料；更新前也可在「設定與備份」另存完整備份。

附件 `toeic-vocabulary.json` 是完整教材，補充教材與匯入規則見 [教材說明](https://github.com/ming0071/Wording/blob/v0.4.0/content/README.md)。
