# Wording 0.4.1

修正刪除詞義後的列表對齊與搜尋範圍，並提供固定的本機程式路徑。此版本目前僅更新原始碼與本機程式包，尚未發布 GitHub Release。

## 修正

- 原本有兩組解釋的詞條，刪除其中一組並儲存後，回到列表時剩下的詞義會重新垂直置中；多組解釋也維持置中排列。
- 單字庫搜尋統一比對詞條名稱與目前各組中文詞義，忽略英文大小寫與首尾空白。搜尋 `colleague` 不會再因 `fill in for a colleague` 這個常見搭配而顯示 `fill in`。

## 固定程式路徑

本機成功打包後，會同步更新 `artifacts/Wording-current/Wording.exe`，方便建立捷徑與釘選到工作列。更新先準備完整副本；程式仍在執行時會中止並保留原檔。一般開發建置不會同步，也沒有自動下載 GitHub 新版。

個人詞庫與練習紀錄仍保存在 `%LOCALAPPDATA%\Wording`，不包含在程式包內。

## 驗證

回歸測試涵蓋實際編輯、刪除一組解釋、儲存及重新載入列表，在不同視窗寬度下檢查詞義置中；搜尋測試同時檢查列表與資料層的結果一致。固定路徑更新另驗證首次建立、原路徑替換、舊檔清除、不完整來源保留現有程式，以及執行中禁止更新。
