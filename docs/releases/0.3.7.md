# Wording 0.3.7

讓生成選項跟隨 Codex 更新，也讓複習操作更順手。

## Changes

- 「設定與備份」新增動態模型與生成速度選單。開啟設定頁或按「更新模型清單」查詢目前 CLI 提供的模型與加速模式，閱讀、聽力及詞義生成共用保存的選擇。
- 預設維持標準速度；Fast 的速度說明依模型清單顯示，會消耗較多訂閱額度。清單失效或模式不支援時保留原選擇並提示重新選取。
- 單字庫、複習卡及練習單字回顧的星號改為橘色圓底、白色星形，未標星時使用淡色底；保留鍵盤焦點及輔助閱讀名稱。
- 開始複習時切換到已安裝的英文輸入語言，複習頁停用中文組字，讓快捷鍵可以直接操作；離開後恢復原輸入語言。
- 每日新詞預設改為 25 個，到期複習另計；已保存的個人數量不會被覆蓋。
- 程式預設集中至 `Configuration/app-defaults.json`，包含文章字數、選字權重、紀錄期間、AI 次數與逾時；版本統一來自 `Directory.Build.props`。

## Validation

188 項 .NET 測試通過，包含模型清單分頁、後續新增模型及加速模式、選單繫結、設定保存、舊設定預設、閱讀／聽力傳遞加速設定，以及星號操作與畫面檢查。Windows x64 發行包另經套件與校驗碼檢查。

## Update

完整解壓 Windows x64 ZIP 後執行 `Wording.exe`。單字與複習資料仍存放於 `%LOCALAPPDATA%\Wording`，個人設定保留；新設定不修改資料庫排程。實際輸入法切換效果依已安裝的 Windows 輸入法驗收。
