# Wording 1.0.0

整合中翻英文字練習與複習頁的例句錄音辨識，所有朗讀統一使用 Windows 本機英文語音。

- 中翻英練習從較不熟悉或標星的詞彙出題，支援文字作答、AI 批改與修改後重答。練習結果不影響單字熟悉度、FSRS 排程及每日新詞數。
- 在複習頁的例句下方錄音、回聽及查看辨識文字，標示不同、漏字與多字。錄音辨識使用個人 Codex 訂閱登入，不提供發音分數，也不影響複習進度。
- 進入複習即背景準備辨識連線，開始錄音才開啟麥克風；同頁共用連線，暫時斷線最多等待 15 秒恢復，待命連線失效時最多自動重試 3 次。
- 錄音預設空白鍵、回聽預設 R、下一句預設 N，皆可在設定自訂。下一句循環切換同一單字的所有例句，Ctrl+↑／↓ 也可切換；正面空白鍵仍用於翻卡。
- 單字、例句、自動朗讀與情境聽力皆使用 Windows 本機英文語音。例句可單獨朗讀，Esc 可停止發音；不顯示停止發音按鈕。
- 移除 AI 發音原型、額外語音連線、背景預載與音檔快取。舊設定即使選擇 AI 發音，也直接使用 Windows 語音。
- 設定頁的「保存並檢查 Codex」採用主題色。

下載 `Wording-1.0.0-win-x64-Setup.exe` 安裝或更新，個人詞庫、學習進度與設定沿用原資料目錄。錄音辨識仍依賴 Codex 的實驗性介面及網路連線；本機朗讀不需連網。
