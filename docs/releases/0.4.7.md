# Wording 0.4.7

取消因到期複習量自動減少或暫停新詞的規則，學習量由使用者決定。

- 一般複習仍先提供所選範圍中已到期的詞，沒有到期詞時，再依設定的每日上限提供新詞。
- 到期卡數不會降低新詞上限；舊版本儲存的減量名額立即失效，更新當天即可繼續學習。
- 今天已開始的新詞數量、FSRS 排程與學習紀錄保留；所有主題共用每日名額，0 上限與撤銷後保留名額的規則仍適用。
- 新詞名額用完時顯示實際數量與設定上限；上限為 0 時顯示對應原因。
- 情境練習的新詞評分仍可超過設定上限，並計入今天的學習數量。

驗證大量到期卡優先、完成後仍可學滿設定上限、舊減量名額不影響取卡與評分、重啟後計數保留，以及當天調整上限立即生效。更新固定入口 `artifacts/Wording-current/Wording.exe`，本次不建立 GitHub Release。
