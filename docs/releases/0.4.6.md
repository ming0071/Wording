# Wording 0.4.6

情境練習的單字評分可超過每日新詞上限，並補充 AI 協助開發與教材來源。此版本僅更新原始碼與本機程式包，尚未發布 GitHub Release。

- 閱讀與聽力情境練習中，未學新詞可直接評分，即使已達設定上限、上限為 0，或因到期量而減少新詞名額。
- 成功評分的新詞仍計入當天學習數量，畫面顯示實際數量／設定上限，允許 55 / 50。一般複習頁仍依每日名額提供尚未開始的新詞，設定值不會自動提高。
- 同一詞條只計一次；重試與撤銷後重新評分不重複增加新詞數量。未到期、暫停、封存、評分版本衝突與每篇練習一次評分的規則仍適用。
- README 說明程式碼由 AI 協助實作，作者提出開發方向、調整流程與版面並實際驗證。教材文件說明作者詞庫的單字選自《全新！新制多益 TOEIC 單字大全》，例句由網路辭典選用，另有 AI 編寫的起始教材與動詞片語補充。

驗證閱讀與聽力各自從 50 個累積至 55 個、一般複習仍受限、上限為 0、到期量減量、重試、撤銷與實際畫面的進度。固定入口更新至 `artifacts/Wording-current/Wording.exe`，個人詞庫與練習紀錄沿用原本的使用者資料目錄。
