# Wording 1.1.0

改善小視窗的複習閱讀空間，保留大視窗排版與多詞義的左右對齊。

- 小視窗將標題、類別選單與數量整合為「複習 → 全部單字庫 → 已複習 · 到期 · 新詞」，類別可在選單中複選；保存結果改為精簡提示。
- 回憶時整組內容上下置中，單字在回憶與翻卡後皆左右置中。單一解釋使用收窄卡片；多組解釋依寬度排列，英文解釋、提示與例句保留相同列高，常用搭配、同義詞及筆記直接顯示。
- 新增 F 切換最大化與原視窗大小。按住不放只切換一次，輸入文字、操作選單或搭配 Ctrl／Alt／Shift 時不觸發；提示放在複習頁下方快捷鍵列的右側。F 改為保留鍵，舊的 F 學習快捷鍵會改配未使用的按鍵，其他設定保留。
- 每日學習圖表依序使用 0、1～19、20～29、30～39、40 以上五級，圖例滑鼠提示顯示範圍。仍以同一詞義每天計一次，撤銷評分不計入。
- 今日學習的複習入口與到期數量放在一起，方便直接開始複習。
- 例句錄音顯示連線、收音、處理與錯誤狀態；失敗時可直接前往設定，並定位 Codex 路徑欄位。
- 中翻英批改後自動移到第一題回饋，作答與 AI 建議並排顯示。
- 設定頁加入固定保存列與未保存變更提示。

下載 `Wording-1.1.0-win-x64-Setup.exe` 安裝或更新，個人詞庫、學習進度與設定沿用原資料目錄。所有朗讀繼續使用 Windows 本機英文語音，例句錄音辨識使用個人 Codex 訂閱。
