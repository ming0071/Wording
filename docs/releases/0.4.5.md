# Wording 0.4.5

恢復複習卡的垂直置中，保留依視窗寬度調整的一、二、三欄與原本字級。此版本僅更新原始碼與本機程式包，尚未發布 GitHub Release。

- 翻卡前的單字、詞性、提示與朗讀按鈕，連同回想提示一起置中，不再分散在卡片頂部與中段。
- 翻卡後，內容能完整容納時，詞條與所有詞義作為同一組垂直置中。
- 內容超出高度時，保留詞義區的垂直捲動，詞條、朗讀與評分按鈕保持可見，不縮小文字。
- 移除單組詞義的「本次依提示回想這個詞義」，多組詞義仍顯示組數與一起評分的說明。

驗證一至三組詞義在窄、中、寬視窗的翻卡前後置中、提示間距、長內容捲動與固定操作。固定入口更新至 `artifacts/Wording-current/Wording.exe`，個人詞庫與練習紀錄沿用原本的使用者資料目錄。
