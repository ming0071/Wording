# Wording 5.0

版本號為 5.0.0。改用單一 EXE 安裝檔，加入程式內更新通知與下載安裝功能，完整教材也隨程式提供。

- 下載 `Wording-5.0.0-win-x64-Setup.exe` 即可安裝，不需要另外下載壓縮檔、校驗碼或教材。
- 預設安裝到目前 Windows 帳號的 `%LOCALAPPDATA%\Programs\Wording`，提供開始功能表捷徑與可勾選的桌面捷徑，一般安裝及更新不要求管理員權限。
- 開啟程式時及使用期間每六小時檢查 GitHub 最新正式 Release。設定頁可手動檢查、查看說明或略過某一版本。
- 按「下載並更新」後，程式自動下載安裝 EXE 並依 GitHub 附件 SHA-256 校驗。校驗失敗不執行安裝；下載可取消或重試。
- 有未保存的詞義或正在進行的操作時，保留已下載內容，等操作完成再安裝。有未提交的練習時，先詢問是否結束練習；取消會保留當次內容。安裝前先備份學習資料，安裝後重新開啟。
- 完整 `content` 資料夾隨程式安裝，在設定頁選擇匯入完整 TOEIC 詞庫、片語補充或 AI 起始教材。更新程式不自動匯入教材，也不覆蓋個人詞庫。
- 個人詞庫、例句、星號、FSRS 排程、完成紀錄與設定沿用 `%LOCALAPPDATA%\Wording`。解除安裝預設保留這些資料。
- 同時包含 0.4.9 的複習單字雙擊選取複製，以及提示、搭配、同義詞等輔助文字放大。

從舊 ZIP 版首次轉換時，先關閉舊程式，再執行安裝 EXE，之後使用新捷徑；不需要手動搬移預設資料目錄。舊版沒有更新檢查功能，需手動安裝這次版本一次。

發行驗證包含真實的安裝、跨版本升級、執行安裝後的程式讀取既有詞庫、解除安裝與資料保留。對外只提供安裝 EXE，校驗與驗證報告由發布流程管理。
