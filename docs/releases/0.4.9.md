# Wording 0.4.9

複習時可選取並複製單字，翻卡後的輔助文字也更容易閱讀。

- 雙擊詞條會選取完整單字或片語，按 Ctrl+C 複製。翻卡前後都可使用，詞條文字為唯讀。
- 選取單字後，空白鍵翻卡、評分與朗讀快捷鍵仍可使用。
- 提示、常用搭配、同義詞從 14 放大至 17，筆記從 13 放大至 16。輔助欄位標題從 12 放大至 15，並加寬標題欄。
- 翻卡後詞性與英文解釋放大 2 號。單組與多組詞義使用相同字級，保留依視窗寬度調整欄數、置中與長內容捲動。

驗證完整詞條選取、原生複製命令的內容、唯讀狀態、複習快捷鍵，以及一至三組詞義在窄、中、寬視窗的排列。更新固定入口 `artifacts/Wording-current/Wording.exe`，個人詞庫與練習紀錄沿用原本的資料目錄。本次不建立 GitHub Release。
