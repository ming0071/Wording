# Wording 0.4.2

複習卡的多組詞義改為並排呈現，各組沿用相同的字級、文字顏色與例句樣式。此版本目前僅更新原始碼與本機程式包，尚未發布 GitHub Release。

## 複習版面

- 一組詞義使用完整寬度；兩組左右並排；三組左、中、右等寬並排。更多詞義以每列最多三欄排列。
- 每組完整顯示自己的詞性、提示、中英文解釋、常用搭配、同義詞、雙語例句與筆記，空白欄位不占用版面。
- 移除「其他意思」的獨立紫色區塊；所有詞義共用同一個呈現範本，中文解釋、英文例句與中文翻譯的樣式一致。
- 朗讀例句會依詞義順序讀出全部英文例句。整個詞條仍共用一個星號與複習評分。

## 更新與驗證

本機打包會更新固定的 `artifacts/Wording-current/Wording.exe`。個人資料仍保存在 `%LOCALAPPDATA%\Wording`，不包含在程式包內。

版面測試涵蓋一至三組詞義、不同視窗寬度、翻卡前隱藏解釋、各欄等寬與文字樣式一致、不同組數卡片切換，以及全部例句朗讀。既有教材的最小視窗版面測試也檢查所有詞義與例句完整顯示。
