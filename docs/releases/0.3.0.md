Wording 0.3.0 加入閱讀與聽力情境練習，讓自己的單字出現在文章、對話與選擇題中。

## 新增功能

- **閱讀與聽力練習**：選擇主題、情境、長度、難度和目標單字量，生成單篇內容與 3–5 題英文選擇題。也能選輕鬆故事、科幻或奇幻內容。
- **作答與中文解析**：提交後顯示分數、正確答案、文章依據、各選項解析及目標單字；全文翻譯需自行展開。
- **Windows 英文朗讀**：聽力支援播放、暫停、繼續、停止與速度調整，提交答案後才顯示逐字稿。
- **個別單字回饋**：到期詞義與未學新詞可評分並更新 FSRS；新詞使用每日名額。測驗分數不會自動改寫排程。
- **主題練習足跡**：以最近三個月的主題熱力圖、閱讀／聽力次數與最近日期，查看各主題練習情況。文章、答案與分數不保存為歷史紀錄。
- **可調整的生成提示詞**：閱讀、聽力及共用提示詞放在程式包的 `Prompts` 資料夾。

## 操作與修正

- 文章與題目左右對照、各自捲動；修正滑鼠停在選項上時無法捲動題目的問題。
- 設定與練習足跡上下排列，整頁可捲動，不需展開選單。
- 生成成功後隱藏生成選項，仍可重新設定或返回當次作答。
- 切換練習的提示沿用 App 的圓角與配色，預設保留當次作答。
- 未提交的內容與答案可跨頁保留；生成失敗時保留原本練習。
- 修正閱讀題型驗證，生成失敗時提供更明確的原因。
- 未學單字的評分區顯示每日名額限制及設定入口。

## 下載與使用

1. 下載 `Wording-0.3.0-win-x64.zip`，完整解壓後執行 `Wording.exe`。程式包包含 .NET，不需另行安裝。
2. 內嵌字典需要 Microsoft Edge WebView2 Runtime；聽力需要 Windows 英文語音。
3. AI 生成需要使用者已登入的 Codex CLI，可在「設定與備份」指定執行檔並檢查連線。
4. 新安裝的詞庫為空。可自行新增單字，或匯入附件 `toeic-vocabulary.json`（1,323 個詞義、8 個主題）。

附有 ZIP 的 SHA-256 校驗碼。此次發行通過 146 項自動測試。

完整操作說明：[閱讀與聽力情境練習](https://github.com/ming0071/Wording/blob/v0.3.0/docs/scenario-practice.md)。
