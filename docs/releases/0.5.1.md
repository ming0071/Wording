# 0.5.1

- 新增獨立的「中翻英練習」頁面，支援 3／5 題中文句子、指定單字與詞義、文字作答及 AI 批改。
- 從未學習、學習／重學中、穩定度較低、回想機率較低或已標星的詞彙中選字；排除暫停、封存及略過詞彙，合格詞不足時減少題數。
- 批改分別說明意思、指定單字及文法，接受不同的正確翻譯；可修改答案再批改，參考譯句於批改後顯示。
- 中翻英只作練習，出題、提交與重答都不影響單字熟悉度、FSRS 排程、複習紀錄與每日新詞數。
- 沿用個人 Codex 登入與 AI 設定。頁面切換保留當次答案，取消或失敗保留原內容，關閉程式後清除。

本次更新本機固定入口 `artifacts/Wording-current/Wording.exe`，提交並推送程式碼，不建立或更新 Git tag，也不發布 GitHub Release。
