# 0.5.3

- 複習頁新增例句朗讀辨識，錄音控制、辨識文字與不同／漏字／多字比對放在例句下方。
- 使用本機 Codex 訂閱登入與實驗性 realtime v3 WebRTC 介面；進入複習即背景預連線，開始錄音才開啟麥克風。
- 同頁錄音共用連線；暫時斷線最多等待 15 秒恢復，待命連線失效時最多自動重試 3 次，離開複習即停止連線。
- 開始／結束錄音預設使用空白鍵，回聽預設使用 R，可在設定自訂；正面空白鍵仍用於翻卡，並保留 Esc 取消及 Ctrl+↑／↓ 切換例句。
- 錄音與比對結果不影響熟悉度、FSRS 排程及每日新詞數；換卡清除錄音與結果。此功能只比對辨識文字，不提供發音分數。
- 新增設定遷移、按鍵衝突檢查、快捷鍵與文字比對測試，以及打包語音資源的完整性檢查。

已通過 300 項程式測試、23 項打包測試，並以隔離詞庫及合成英文音訊驗證實際連線、錄音前後閒置、取消重試、暫時斷線恢復、自動重連與頁面切換。

本次更新本機固定入口 `artifacts/Wording-current/Wording.exe`，不建立 Git tag 或 GitHub Release。
