# 例句朗讀辨識原型

自 0.5.3 起整合至複習頁。本機固定入口為 `artifacts/Wording-current/Wording.exe`，語音辨識仍使用 Codex 的實驗性介面。

## 試用

1. 從固定入口開啟 Wording，進入複習。語音連線會在背景準備，不等待點錄音，也不取得麥克風；可先繼續翻卡。
2. 翻卡後，第一個例句下方顯示朗讀控制列。其他例句可按「練習此句」或以 Ctrl+↑／↓ 切換。
3. 正面預設以空白鍵翻卡；顯示答案後，按「開始朗讀」或空白鍵才開啟麥克風，音訊即以 WebRTC 傳送至 OpenAI 辨識。
4. 讀完再按空白鍵，辨識出的英文及吻合／不同／漏字／多字會顯示在同一句下方。
5. R 回聽錄音；Esc 取消。設定與備份的「複習快捷鍵」可自訂錄音與回聽。翻卡可與其中一項共用，依正反面分工；其餘同時可用的操作不可重複。在可編輯輸入欄位中不攔截文字操作。

每次最多收音 30 秒。結束或取消即停止麥克風，同一複習頁保留語音連線供下一次使用；離開複習或關閉程式才結束連線。換卡清除當張卡的錄音與結果，收尾中的舊結果不能寫入新句子。連線失敗可按「重新連線」。

沒有設定閒置數秒就自動斷線。WebRTC 暫時進入 disconnected 時保留原連線，最多等 15 秒恢復；failed、資料通道關閉或超過等待時間才視為連線失效。已成功連線且處於待命時，失效會在背景嘗試重連，最多連續 3 次，間隔 1／3／8 秒；穩定連線 30 秒後重置重試額度。重連不自動開麥克風或重錄。正在錄音時的斷線會停止收音並提示重試。

錄音與結果只保留在當次頁面的記憶體中，不寫進詞庫、備份或日誌；練習不影響熟悉度與 FSRS。辨識吻合不代表音素、重音與語調都正確。

## 接法與限制

本機 Codex 0.166.0-alpha.5.1 使用官方 App Server 的 ChatGPT 登入，以 experimental realtime v3 WebRTC 接收音訊。不讀取憑證檔，也不需要額外 API key。一般文字模型流程無法直接接受音檔；本機測試中，WebSocket 要求 API key，WebRTC v2 不接受此模式。

這是實驗性介面，其他帳戶或 Codex 版本仍需要實測。預連線不保證網路延遲消失；畫面會顯示準備中或已就緒。只接收使用者轉錄，不播放助理回覆，不把例句原文當作答案提示送給辨識器。語音視為練習材料，停用工具並拒絕服務端工具或核准請求。

比對使用單字編輯距離，忽略大小寫、標點、部分常見縮寫，以及 0–20 的數字／英文表示差異。

## 開發驗證

- `ReadingPracticeTests`：文字比對、舊結果隔離、快捷鍵、不改變學習資料。
- 忽略 Git 的 `artifacts/codex-voice-probe`：以隔離詞庫及合成英文音訊，實測 WPF 複習頁、WebView2、Codex 訂閱、無麥克風預連線、共用連線連續錄音、回聽、取消重試、句子切換及離開／返回生命週期。結果見 `inline-pass.txt`、`inline-result.json`、`inline-review.png`。
- 真人麥克風與背景噪音需實際試用。

開發時仍可執行 `scripts/build-reading-prototype.ps1` 產生獨立輸出；該腳本不更新固定入口。使用 `scripts/publish.ps1 -LockedRestore` 建置並更新固定入口。
